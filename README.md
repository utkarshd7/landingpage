# 🚀 NovaAI - Modern Landing Page

A modern, responsive and visually appealing landing page built using
HTML, CSS and JavaScript.

NovaAI is a SaaS/AI-themed landing page designed to demonstrate
modern web design, responsive layouts, animations and interactive
JavaScript components.

## 📌 About The Project

NovaAI is a modern landing page created for an AI/SaaS product.

The project focuses on:

- Clean and modern UI
- Responsive web design
- User-friendly navigation
- Interactive components
- Smooth animations
- Pricing presentation
- FAQ accordion
- Contact form
- Mobile-friendly layout

The entire project is built using frontend technologies without
requiring any external framework.
